# pillsrs

An endless puzzle/strategy game for the TI 84 Plus CE where you place pillars or slabs on the right and bottom of the screen ~~and have to get as many points as possible~~ <sup>[not added yet]</sup> before filling the screen. When a pillar touches a slab of the same color, all contacting slabs and pillars of the same color are removed, ~~earning points,~~ and the remaining pillars and slabs extend to fill in empty space, if necessary. If extension happens and leads to more connected groups, clears can be chained ~~for extra points!~~

This is my first game, first time developing for the TI 84 Plus CE, and first time using Git/Github, so don't expect perfection, but I hope you have fun with it!
